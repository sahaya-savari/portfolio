# Contributing

Thank you for visiting the **Sahaya Savari F Portfolio** repository (`sahayasavari.dev`).

This repository serves as a personal portfolio, professional resume, and technical showcase owned and maintained by **Sahaya Savari F**.

---

## Contribution Policy

- **Public Reference & Evaluation**: This repository is publicly available on GitHub for transparency, code review, technical evaluation, and educational reference purposes.
- **Not an Open-Source Project**: This repository is **not released under an open-source software license**.
- **No External Code Contributions**: External pull requests, code modifications, derivative works, redistribution, and unauthorized reuse of the portfolio's original source code, design, branding, assets, or content are not currently accepted without prior written permission from Sahaya Savari F.
- **Authoritative License**: The repository's [LICENSE](LICENSE) file governs all usage rights and restrictions.

---

## Feedback, Issues & Vulnerabilities

While external code contributions are not accepted, feedback and vulnerability reports are welcome:

- **Source Inspection**: Visitors are welcome to inspect and review the source code for learning and technical evaluation.
- **Bug & Issue Reports**: If you discover a bug or broken link on the portfolio website, feel free to open a GitHub Issue describing the problem.
- **Security Vulnerabilities**: If you discover a security vulnerability or security concern, please report it privately by following the instructions in [SECURITY.md](SECURITY.md) (send details to [contact@sahayasavari.dev](mailto:contact@sahayasavari.dev)).
- **Feature Suggestions**: Suggestions or constructive feedback may be submitted via GitHub Issues and will be considered at the owner's discretion.
- **Pull Requests Notice**: Submitting a pull request or opening an issue does not grant permission to copy, reuse, modify, or redistribute the project's code or original assets.

---

## Development Guidelines (Authorized Maintainers)

When authorized maintainers or AI coding assistants work on this repository locally:

1. **Preserve Architecture**: Maintain existing React 19, TypeScript, Vite 7, static HTML pre-rendering, and Firebase Hosting architectures.
2. **Follow Local AI Guidelines**: Adhere to `AI_PROJECT_CONTEXT.md` and `AI_AGENT_WORKFLOW.md` when operating locally with AI coding assistants.
3. **Keep AI Context Private**: Never commit or expose `AI_PROJECT_CONTEXT.md` or `AI_AGENT_WORKFLOW.md` in public version control. Keep both files ignored in `.gitignore`.
4. **Protect Secrets**: Never hardcode, stage, or commit `.env` files, API keys, credentials, private tokens, service keys, or local AI-agent data.
5. **Build & Test**: Execute `npm run build` to verify static HTML pre-rendering across all 9 canonical routes before deploying production changes.
6. **Infrastructure Safety**: Do not modify hosting, domain registration, DNS records, or edge proxy configurations without explicit authorization.
